# 上海市支持创业投资高质量发展若干举措

## 基本信息

| 字段 | 内容 |
|------|------|
| 发布机构 | 上海市地方金融监督管理局 |
| 适用地区 | 上海 |
| 发布日期 | 2024-06-15 |
| 申报截止 | 2025-12-31 |
| 一级分类 | 资金支持 |
| 二级分类 | 后补助/奖励 |
| 政策类型 | 补贴 |
| 资助金额 | 最高100万元 |
| 关键词   | — |
| 来源链接 | https://jrj.sh.gov.cn/example/vc2024.html |

## 申报条件

在沪注册、已开展科创板上市辅导或完成天使轮融资、净资产≥2000万

## 摘要

对在沪注册并启动科创板上市辅导的企业给予一次性奖励50万元；对天使轮融资的科创企业按融资额10%给予补贴，上限100万元。
