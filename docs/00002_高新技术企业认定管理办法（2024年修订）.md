# 高新技术企业认定管理办法（2024年修订）

## 基本信息

| 字段 | 内容 |
|------|------|
| 发布机构 | 科技部 财政部 国家税务总局 |
| 适用地区 | 全国 |
| 发布日期 | 2024-01-01 |
| 申报截止 | — |
| 一级分类 | 资质认定 |
| 二级分类 | 高新技术企业 |
| 政策类型 | 减税、资质 |
| 资助金额 | 减按15%税率 |
| 关键词   | — |
| 来源链接 | https://www.most.gov.cn/example/hnte2024.html |

## 申报条件

研发费用占比≥3%（5千万以下≥5%），科技人员≥10%，高新产品收入≥60%

## 摘要

高新技术企业享受15%优惠税率（普通25%），须满足研发费用占比、人员比例、知识产权等条件，每3年复审一次。
